# 実例: Pita 2019 "Optimal bidding: a dual approach"（KDD 2019, Jampp）

目的 c（手法の習得: 緩和 → ラグランジュ → 双対 → 劣勾配の鎖を追う）で要約した例。
自タスクは「CPC 課金で予算制約つき CPA 最適化入札の乗数 λ を消化誤差で制御する」。

```
1 行要約: DSP 利益最大化を 2 契約で定式化し、連続緩和とラグランジュ双対で 1 件ごとの入札則を導き、乗数を日次の劣勾配降下で更新する
関連度: A（自タスクの λ 制御と同じ鎖。6〜8 章を照合する）

h3. 1 基本（Def 1〜4）

|_. 記号 |_. 意味 |
| n, i, j ∈ [n] | キャンペーン数と添字 |
| m, k ∈ [m] | オークション数と添字 |
| a ∈ [ā] | 広告の添字 |
| b ∈ (0, b̄] | 入札額 |
| w_k(b) | 入札 b での落札確率 |
| c_k(b) | 落札時の期待コスト |
| e_k(i, a) | 落札時のイベント発生確率 |
| x | 入札戦略（k → (i, a, b)） |
| C_i(x), E_i(x) | i の総コスト、総イベント数 |

h3. 2 契約 2 種（Def 5〜6）

|_. 記号 |_. 意味 |_. 契約 |
| B̂_i | 予算上限 | MBFP |
| p̂_i | イベント単価（固定） | MBFP |
| f(x), g(x) | 利益、制約 p̂_i E_i − B̂_i | MBFP |
| b̂_i | 支払総額（固定） | FBMP |
| P̂_i | イベント単価の上限 | FBMP |
| M̂_i | 粗利率の上限 | FBMP |

h3. 4〜5 双対

|_. 記号 |_. 意味 |
| θ* ≤ 0 | 予算制約の乗数（MBFP） |
| θ*_1i, θ*_2i, θ*_3i | FBMP の 3 制約の乗数 |
| L(x, θ*) | ラグランジアン |
| u_k(i, b, a) | 1 オークションの L への寄与 |
| q(θ*) | 双対関数 sup_x L |

h3. 6〜8 凸化と劣勾配

|_. 記号 |_. 意味 |
| θ | 制約の緩め幅（摂動） |
| p(θ) | 摂動後の最適値 |
| p*, p** | Fenchel 共役、凸閉包 |
| g_t | ステップ t の劣勾配 = g(x*) |
| α, α_t | 学習率 |
| G | 劣勾配ノルムの上限 |
| g̃(x*) | 実現値から作った g の推定 |

読むときの注意点
* b は入札額、b̂_i は FBMP の総額で、別の量
* θ* の星は最適の意味ではなく乗数の記号。θ は摂動幅で 6 章だけ主役
* p(θ) の p は単価 p̂_i と無関係
* 7〜8 章の δ（最適値との差）は 6 章のスラック δ と別物
* 教科書の min f、λ ≥ 0 に対し、本論文は max f、θ* ≤ 0。θ* = −λ で対応

h3. 1 導入と準備

ref. 1 INTRODUCTION AND PRELIMINARIES

DSP は多数のキャンペーンを抱え、毎日数十億件の入札を行う
→ 利益最大化に、各クライアントの契約制約が付く
→ 制約の shadow price を入札に織り込む必要がある
→ 整数の割当問題で、厳密解は現実的でない
→ 緩和して近似解を得る方針
→ 記号を定義（w_k、c_k、e_k、C_i / E_i）

h3. 2 契約 2 種の定式化

ref. 2 MBFP AND FBMP BIDDING PROBLEMS

契約は 2 種類
→ MBFP: イベント単価固定・予算上限（max Σ(p̂_i E_i − C_i)、p̂_i E_i ≤ B̂_i）
→ FBMP: 総額固定・単価上限・粗利率上限（max Σ(b̂_i − C_i)）
→ 目的関数はどちらも DSP の利益
→ 金額に揃えたので、契約種別をまたいで 1 つの問題として解ける

h3. 3 連続緩和

ref. 3 MBFP CONTINUOUS RELAXATION

オークション選択の出発点はナップザック問題
→ ただしナップザック問題は NP 困難
→ なら比価値の高い順に詰め、最後の 1 個は入り切る分だけ分割すればよい
→ Dantzig の連続緩和で解消
→ キャンペーンが複数だと「どれが買うか」が加わる
→ 交換論法: k の一部を i から j に移して得なら元の割当は非最適
→ ω_ik(ρ_ik − ρ_{ik_i*}) が最大かつ正の i に割り当てる
→ 問題は「予算をちょうど使い切る ρ ベクトル探し」に変わる（7〜8 章）

h3. 4 MBFP の双対問題

ref. 4 MBFP DUAL PROBLEM

3 章の則は直観頼みで収束の保証がない
→ ラグランジュ緩和で同じ則を導き直す
→ L = f(x) + ⟨θ*, g(x)⟩ はオークションごとの項 u_k の和
→ θ* を固定すれば、k ごとに u_k を最大化すればよい（Rule 7）
→ 2nd price なら b* = (1 + θ*_i) p̂_i E_k で閉じた式
→ 双対関数 q(θ*) = sup_x L、双対問題は θ* ≤ 0 で q を最小化
→ Rule 7 は 3 章の則と一致（θ*_i = −ρ_{ik_i*}）

h3. 5 FBMP の双対問題

ref. 5 FBMP DUAL PROBLEM

FBMP も同じ手順
→ 制約 3 本に乗数 θ*_1i, θ*_2i, θ*_3i
→ u'_k を整理すると、やはり k ごとの最大化（Rule 10）
→ 2nd price の最適入札は閉じた式
→ 双対関数 q'、双対問題も MBFP と同形

h3. 6 凸化

ref. 6 CONVEX RELAXATION

双対を解いて得るのは主問題の解そのものか
→ 摂動関数 p(θ): 制約を θ だけ緩めたときの最適値
→ q は p の Fenchel 共役の符号違い（q は常に凸）
→ 双対の最適値は p** = cl p（p の凸閉包）の値
→ p が凸なら一致、そうでなければ差が双対ギャップ（Prop 3）
→ 件数が膨大で 1 件が小さいなら p はほぼ凸と見込む。証明はなく仮定

h3. 7 劣勾配降下

ref. 7 SUBGRADIENT DESCENT FOR THE DUAL

q は凸で、内側の解 x* の制約値 g(x*) が劣勾配（Prop 2）
→ 劣勾配の負方向は降下方向とは限らない
→ ただし学習率が小さければ最適点に近づく（Prop 4）
→ 最良値と最適値の差の上界を導出（Prop 5）
→ 定数学習率なら誤差 ε + αG²/2 まで対数的に収束（Prop 6）

h3. 8 ノイズ下の劣勾配降下

ref. 8 SUBGRADIENT DESCENT WITH NOISE

実運用では w, c, e の期待値ではなく実現値しか観測できない
→ 観測した g̃ が不偏推定なら、Prop 5 の結果は期待値で保持（Prop 7）
→ g が平均の線形結合なので不偏は妥当
→ 前日の g̃ を翌日の推定に使う（定常性の仮定）
→ 学習率を下げ切らず、季節変動や構造変化に追従させる
→ 日次: 各 k で u_k 最大化 → 日末に θ* を 1 歩更新

h3. 9 結論

ref. 9 CONCLUSION AND FUTURE WORK

2 契約の入札を少数の仮定から理論的に導いた
→ 連続緩和とラグランジュ緩和は RTB では既出（Grigas 2017）
→ 貢献は契約形態への拡張、仮定の分析、ノイズ対応
→ 弱点は実証がないこと。ギャップの上界と A/B 結果は続報

MEMO: 自タスクの緩和後の問題は線形計画なので強双対が自動で成り立ち、6 章に当たる議論は不要。7〜8 章の「消化誤差を劣勾配にする」「不偏なら期待値で収束」が λ 制御の根拠になる
```

この例で意図している粒度

- 1 行 1 事実。「→」の前後が因果か順序になっている
- 章の冒頭は「問題」か「前章の残課題」、末尾は「結論」か「次章への引き渡し」
- Prop / Def / Rule の番号で原文に戻れる
- 要約者の補足は MEMO に分け、著者の主張と混ぜない
