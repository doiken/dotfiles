# Notion 書き込み

会話の内容を Notion に書き込む。「本文は簡潔、細部は折りたたみ、配置は適切な階層」の3点を守る。

## 前提

- notion MCP が未接続ならツールは使えない。`/mcp` での接続をユーザーに案内して中断する
- 書き込み前に、内容が会話の原文・ツール結果と一致しているか照合する（note スキルと同じ再確認ルール）

## タイトル

既存ページの命名傾向(目標 / 健康 / 採用 / 消化改善 / CVR 予測 / mac setup 等)に合わせる:

- **名詞のみ・最短**で付ける。2〜8字程度が目安(例: 「抗真菌シャンプー比較メモ」ではなく「抗真菌シャンプー」)
- 「メモ」「まとめ」「比較」「〜について」等の説明サフィックスは付けない。内容は本文が語る
- 英語は小文字可(mac setup 等)。区切りが要るときは「仕様/フロー」のように `/` を使う

## ページアイコン

アイコンを設定・修正するのは**トップレベルから2階層目まで**。3階層目以降はデフォルト（無地）のままにする。

- 1階層目: 大カテゴリ（🏠 PRIVATE / 🐜 WORK / 🎷 FOUT）
- 2階層目: 大カテゴリ直下のサブページ（例: `PRIVATE > 買い物・購入検討`）
- 3階層目以降: 設定しない（例: `PRIVATE > 買い物・購入検討 > スポット回線` はデフォルトのまま）

既存ページのアイコンが上記に反していても、依頼された範囲外なら勝手に直さない。

## ページフォーマット

構成は必ずこの順にする:

```
> 🤖 Claude Code による記入（作成: YYYY-MM-DD）

（本文: 簡潔なまとめ）

<details>
<summary>詳細（調査ログ・出典）</summary>
（細部の情報）
</details>
```

### 冒頭
- 1行目に Claude Code による記入であることと作成日を引用ブロックで明記する
- 更新時は「最終更新: YYYY-MM-DD」を追記する（作成日は残す）

### 本文（簡潔に）
- 冒頭に概要を100字程度、続けて結論・TODO を箇条書き
- 表・リスト（ネスト含む）中心。1行50字以内を目安
- 冗長な説明・前置き・まとめは書かない
- 見出し（##, ###）で構造化し、リンクはそのまま含める

### 末尾の折りたたみ
- 追加調査のとき参照する細部は本文に入れず、末尾の `<details>` に寄せる
- 入れるもの: 出典 URL 一覧、比較検討の過程、ボツ案と理由、生データ、経緯
- 本文だけ読めば結論が分かり、深掘りしたいときだけ開く、という分担にする

### 分量が大きいとき(階層分割)

1ページの目安は2画面(およそ100行)以内。テーマが大きく収まらない場合は詰め込まず階層に分ける:

- 親ページ: 概要・結論・TODO と、子ページへのインデックスのみ
- 子ページ: テーマを1つに絞り、それぞれ通常フォーマット(冒頭表記+末尾折りたたみ)で書く
- 子ページのタイトルも名詞のみの簡潔表記(親と重複する語は省く。例: 親「脂漏性皮膚炎」子「シャンプー」)
- 分割の目安判断に迷う場合、無理に分割せずまず1ページで作り、育ってきたら分割を提案する

## 配置先の決定

トップレベル（ワークスペース直下）には置かない。必ず既存ページの配下に入れる。

1. `references/category-map.md` を読む（毎回の全検索を避けるための事前マップ）
2. マップから大カテゴリ（PRIVATE / WORK / FOUT）→ サブページの順に絞る
3. 迷ったら候補2〜3件の選択式でユーザーに確認する（自由入力は求めない）
4. マップに合う配置先がない場合のみ notion-search や親ページの fetch で探す

### 既存ページの確認
新規作成の前に、同じトピックの既存ページがマップ・検索で見つからないか確かめる。
同一トピックのページが増えると次回の配置判断が壊れるため、見つかったら新規作成しない。
既存ページへの反映は追記後の分量で判断する:

- 追記しても2画面（約100行）に収まる → そのまま追記・更新（update-page / insert_content）
- 収まらなくなる → 「分量が大きいとき」の規定どおり階層分割する
  （既存ページを親に再編し、既存内容と追記内容をテーマ別の子ページへ振り分ける）

### マップのメンテナンス
- マップにないサブページを fetch で発見した場合や、新しい配置先にページを作った場合は、
  `references/category-map.md` に追記して次回以降の検索を省く
- マップの記載と実際の構造がずれていたら、気付いた箇所だけ直す

## 事後報告

書き込み後は次を1〜2行で報告する:
- ページへのリンク
- 配置場所（例: `PRIVATE > 健康 > ◯◯`）
- 新規作成か更新か
