# 転記用ノート出力

会話の内容を、Notion等への転記に適した形式で出力する。

## 出力ルール

- 冒頭に概要を 100 字程度記載する
- 結論や TODO も続けて箇条書きで簡潔にまとめる
- 表・リスト（ネスト含む）を積極的に使う
- 1行は短く、50字以内を目安にする
- 冗長な説明・前置き・まとめは不要
- 見出し（##, ###）で構造化する
- リンクがあればそのまま含める
- コードブロックは必要な場合のみ

## 再確認（出力前に必ず実施）

- まとめる内容に誤りがないか、会話の原文と照合して確認する
- 根拠に基づいているかを検証し、出典（会話中のどの発言・ツール結果か）も追記する

## 引数の解釈

`$ARGUMENTS` の内容に応じて動作を変える。

### 引数なしの場合
これまでの会話全体を要約して出力する。
- 主要な結論・決定事項を先に
- 比較検討の過程は表で簡潔に
- 未決事項があれば末尾にリスト化

### 引数ありの場合
引数の内容を以下のように解釈する:

1. **出力対象の指定**（例: `候補の比較`, `候補の検証方法`）
   - 該当する話題だけを抽出して出力
2. **出力先の指定**（例: `todo.txt`, `/path/to/file.md`）
   - 指定ファイルに書き込む
3. **両方**（例: `候補の比較 todo.txt`）
   - 指定内容を指定ファイルに書き込む
4. **自由指示**（例: `箇条書きだけで`）
   - 指示に従ってフォーマットを調整

判断に迷う場合はユーザーに確認する。
