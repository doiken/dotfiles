# 転記用成果物の文字数・構成の目安

Redmine・Notion に転記する資料を書くスキルから参照する。チャットの回答には CLAUDE.md の「体裁の目安」だけを適用し、ここの全体量の目安は当てない。

数値は「目安 / 上限」。目安は本人の実測の中央値、上限は p75〜p90 を丸めた値。条件・根拠を削ってまで上限に収めない。超える分は折りたたみに回す。

出典: 2026-10-16 に本人の Redmine を実測(タイトル 98 件、説明文 15 件、注記 48 件。Science の調査系バックログ中心)

## 1. 要素ごとの文字数

| 要素 | 目安 | 上限 |
|---|---|---|
| Redmine タイトル([タグ] を除く) | 20字 | 30字 |
| Notion タイトル | notion-write スキルに従う(2〜8字) | - |
| h2 見出し | 2〜6字 | 10字 |
| h3 見出し | 10字 | 20字 |
| h4 見出し | 20字 | 30字 |
| リスト第1階層の1項目 | 25字 | 45字 |
| リスト第2・3階層の1項目 | 30字 | 50字 |
| 1親あたりの子の数 | 2個 | 4個 |
| 表のセル | 5字 | 15字(補足列は20字) |
| 表の大きさ | 3列・7行 | 5列 |
| 1行(改行まで) | 30字 | 50字 |
| 地の文の1段落 | 1行 | 2行 |
| 結論の1行 | 40〜60字 | 60字 |
| 冒頭の概要 | 100字 | - |

## 2. 全体量

| 対象 | 目安 | 上限 |
|---|---|---|
| Redmine 説明文 | 250字 | 800字(プロジェクトチケットは1600字) |
| Redmine 注記1件 | 180字 | 600字。超える分は折りたたむ |
| Notion 1ページ | - | 約100行。超えたら階層に分ける |

## 3. 文末

体言止めと用言の言い切り(「〜する」「〜ある」)で書く。です・ます調は報告向けの注記に限る。

## 4. 構成

### 4-1. Redmine 説明文

h2 概要(目的・背景)→ h2 まとめ。まとめは結論1行、「以下、詳細。」、注記へのリンク(#チケット#note-N)付きの要約の順に置く。プロジェクトチケットは redmine-project-ticket スキルの構成に従う。

### 4-2. Redmine 注記

h3 見出し(10字前後)、ref. URL、箇条書き3〜10項目の順に置く。考察・残作業・後からの補記は「MEMO:」「TODO:」「【追記】」で本文と分ける。仮説を書いたときは、後で「→ Yes/No」で答え合わせを追記する。

### 4-3. 折りたたみ

- 開いたままの本文には、結論とその根拠だけを置く
- 折りたたむもの: AI の出力、調査の履歴、コード、ログ、比較の過程、ボツ案
- 未検証の内容を折りたたむときは、未検証であることを本文側に書く
- 折りたたみの量は全体の1〜2割が目安。それを超えるなら別の注記・子ページに分ける

### 4-4. 長く書いてよい場合

一次情報の検証、検証計画の設計、数値根拠の列挙。この場合も1項目は30〜60字、階層は3段までに収める。
